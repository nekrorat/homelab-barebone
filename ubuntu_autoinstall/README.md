# Ubuntu Server Autoinstall Files

This directory contains templates and an interactive setup script for generating
Ubuntu Server Autoinstall `user-data` and `meta-data` files. The generated
configuration is intended for unattended installation of bare-metal Kubernetes
nodes.

## What the script does

[`setup_files.sh`](./setup_files.sh) prompts for the machine's hostname and the
initial user's details. It then:

- creates a SHA-512 password hash
- substitutes the supplied values into the templates
- creates the `output` directory when it does not exist
- writes `output/user-data` and `output/meta-data`

## Requirements

- `bash`
- `envsubst`, provided by the `gettext-base` package on Ubuntu/Debian
- `openssl`

```bash
# verify the required commands are available
command -v envsubst
command -v openssl

# install the required packages on Ubuntu or Debian
sudo apt update
sudo apt install gettext-base openssl
```

## Usage

From the root folder, run:

```bash
./ubuntu_autoinstall/setup_files.sh
```

Enter the requested values:

- **Hostname**: the hostname assigned to the installed server, such as
  `k8s-node-01`.
- **Real name**: the display name for the initial user.
- **Username**: the initial user's login name.
- **Password**: the initial user's password.

After successful generation, the files are available at:

```text
output/
├── user-data
└── meta-data
```

Running the script again overwrites both generated files. Review them before
supplying them to the Ubuntu Server installer.

## Templates

- [`templates/user-data.template`](./templates/user-data.template) contains the
  Autoinstall and cloud-init configuration.
- [`templates/meta-data.template`](./templates/meta-data.template) sets the
  NoCloud instance ID to the supplied hostname.

The script replaces these variables automatically:

| Variable | Value |
| --- | --- |
| `${HOSTNAME}` | Server hostname |
| `${REALNAME}` | Initial user's display name |
| `${USERNAME}` | Initial user's login name |
| `${PASSWORD_HASH}` | SHA-512 password hash generated by OpenSSL |

Edit the templates to change settings such as locale, keyboard layout, SSH
access, packages, or update behavior. Keep the variable names above intact if
you want the setup script to continue filling them in.

## Security

The script prints the generated password hash for confirmation, and the hash is
stored in `output/user-data`. Treat the generated files as sensitive. The
repository's `.gitignore` excludes files in `ubuntu_autoinstall/output/` to help
prevent committing credentials.
